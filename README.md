# Saaz - Pakistani Hand-Crafts & Home Decor

This is my solution to the **Landing Page** project from [The Odin Project's Foundations Course](https://theodinproject.com). The goal was to build a professional-looking website from scratch using HTML and CSS, specifically focusing on **Flexbox**.

##  The Brand: Saaz
**Saaz** is a conceptual e-commerce store that sells traditional Pakistani handicrafts (like Multan's blue pottery and Ajrak textiles) reimagined for modern homes.

##  Technical Implementation
   **Flexbox Everything:** I used Flexbox to align the header navigation, the four-column product showcase, and the testimonial section.
   **Custom Typography:** Integrated **Playfair Display** (for that high-end look) and **Poppins** via Google Fonts.
   **Color Palette:** Built around **Saaz-theme** to give the site an organic, artisanal feel.


## Challenges Overcome
   **Alignment:** Getting the hero image and text to sit perfectly side-by-side using `flex: 1`.
   **Spacing:** Learning the difference between `justify-content` and `align-items` to center content within the cards.
   

## 📁 Project Structure
   `index.html` - The structure of the site.
   `style.css` - All custom styling and Flexbox layouts.
   `/images` - Assets for product categories and the hero section.
